# JidoSeal

Local scanner that lists, per file, the frontmatter fields an OKF v0.2 folder is missing for three vendor-defined tiers: Bronze is OKF's required `type`; Silver and Gold add vendor-chosen fields meant to evidence selected ISO 9001 §7.5.2 and ISO 30401 clauses, and are not ISO certification. Pick a folder and scan it with the `jidoseal` CLI or from MCP clients such as Claude Code, Cursor or a local-model client. MCP server Apache-2.0, scan engine proprietary; no network use during a scan is a vendor claim, not independently audited; it writes `.jidoseal/` in the scanned folder. Not affiliated with or endorsed by Google or ISO.
